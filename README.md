# АЛЬМА

Приключенческая 3D-игра для Android на Godot 4.

## Текущий этап
Это первый технический прототип:
- стартовая 3D-сцена;
- управление персонажем с клавиатуры;
- камера от третьего лица;
- первая интерактивная сюжетная улика — медальон;
- базовый интерфейс с целью и подсказками.

## Запуск
1. Установить Godot 4.x.
2. В Godot выбрать **Import** и указать файл `project.godot`.
3. Открыть проект и нажать **F6** или **F5**.

Управление на компьютере: WASD или стрелки — движение, мышь — камера, E — взаимодействие, Esc — освободить курсор.

## План
1. Управление и первая локация.
2. Мобильное сенсорное управление.
3. Персонажи и оригинальные изображения-референсы.
4. Диалоги, загадки и сюжетные сцены.
5. Оптимизация и сборка Android APK.

Проект пока не является готовой игрой или APK. Он будет расширяться проверяемыми этапами.
