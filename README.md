# АЛЬМА — браузерный 3D-прототип

Теперь разрабатываем игру как браузерный 3D-проект на Three.js. Для тестирования в Chrome не нужно устанавливать игровой движок или редактор.

## Как тестировать
После публикации через GitHub Pages игра открывается обычной веб-страницей. Для запуска используется интернет, поскольку Three.js подключается с CDN.

## Сейчас работает
- 3D-опушка леса, свет, туман и окружение;
- персонаж-заглушка от третьего лица;
- движение на WASD и стрелках;
- осмотр мышью;
- интерактивный медальон (подойти и нажать E);
- первая сюжетная подсказка.

## План разработки
1. Доработать управление, камеру и коллизии.
2. Заменить заглушку персонажа на утверждённый образ Ани.
3. Добавить оригинальные образы Альмы, Черныша и Руслана.
4. Построить полноценные локации, загадки и диалоги.
5. Добавить звук, сюжетные сцены и сохранение.
6. После готовности браузерной версии решить вопрос с Android.

Это ранний прототип, а не готовая 30-минутная игра.
